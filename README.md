# 소상공인 정책자금 안내 및 추천 서비스

소상공인이 여러 기관에 흩어져 있는 정책자금 정보를 쉽게 이해하고, 자신의 기업 상황에 맞는 지원 자금을 빠르게 확인할 수 있도록 돕는 웹 서비스입니다.

## 문제 인식

소상공인은 정책자금이 필요해도 다음과 같은 이유로 신청을 어렵게 느낍니다.

- 정책자금을 운영하는 기관이 여러 곳에 나뉘어 있음
- 자금별 신청 조건과 필요 서류가 복잡함
- 심사 과정이 길고 어렵게 느껴짐
- 본인 사업장이 어떤 자금에 해당되는지 판단하기 어려움

이 서비스는 정책자금 정보를 단순히 나열하는 것이 아니라, 사용자의 사업 상태를 기준으로 적합한 자금을 안내하는 것을 목표로 합니다.

## 핵심 목표

- 소상공인이 정책자금 제도를 쉽게 이해할 수 있게 한다.
- 간단한 체크 항목을 통해 신청 가능성이 있는 자금을 추천한다.
- 자금 신청에 필요한 서류와 발급 방법을 한곳에서 안내한다.
- 향후 챗봇 기능을 통해 사용자가 궁금한 내용을 자연스럽게 질문할 수 있도록 확장한다.

## 주요 기능

### 1. 정책자금 기관 소개

정책자금을 제공하거나 연계하는 주요 기관을 소개합니다.

예상 콘텐츠:

- 기관별 역할 소개
- 제공하는 자금 유형 안내
- 공식 사이트 및 신청 페이지 연결
- 기관별 상담 또는 문의 경로 안내

예시 기관:

- 소상공인시장진흥공단
- 중소벤처기업부
- 지역 신용보증재단
- 신용보증기금
- 기술보증기금

### 2. 해당되는 자금 확인하기

사용자가 기업 상태에 해당하는 항목을 체크하면, 조건에 맞는 정책자금을 안내합니다.

예상 체크 항목:

- 사업자 유형
- 업력
- 매출 규모
- 상시 근로자 수
- 업종
- 지역
- 신용 상태
- 창업 여부
- 피해 또는 위기 상황 여부
- 보증 가능 여부

추천 결과에는 다음 정보를 포함합니다.

- 추천 자금명
- 신청 가능성이 있는 이유
- 주요 신청 조건
- 신청 기관
- 필요 서류
- 신청 전 확인해야 할 주의사항

### 3. 자금에 필요한 서류 출력 방법

정책자금 신청에 자주 필요한 서류와 발급 방법을 안내합니다.

예상 서류:

- 사업자등록증명
- 부가가치세 과세표준증명
- 소득금액증명
- 납세증명서
- 지방세 납세증명서
- 4대보험 관련 서류
- 재무제표 또는 매출 증빙 자료
- 임대차계약서

각 서류별로 다음 정보를 제공합니다.

- 서류의 용도
- 발급 가능한 사이트
- 발급 절차
- 온라인 발급 가능 여부
- 발급 시 주의사항

### 4. 챗봇 문의 기능

사용자가 정책자금과 관련된 질문을 입력하면 답변을 제공하는 챗봇 기능입니다.

다만 MVP 단계에서는 개발 범위에서 제외합니다. 우선은 정책자금 소개, 자금 추천, 서류 안내 기능을 먼저 구현하고, 이후 서비스 데이터가 정리된 뒤 챗봇 기능을 추가합니다.

## MVP 범위

초기 버전에서는 다음 기능을 우선 구현합니다.

- 정책자금 기관 소개 페이지
- 기업 상태 체크 기반 자금 추천 페이지
- 필요 서류 및 발급 방법 안내 페이지

MVP에서 제외하는 기능:

- 챗봇 문의 기능
- 사용자 회원가입 및 로그인
- 실제 대출 신청 연동
- 신청 진행 상태 추적
- 기관별 실시간 심사 결과 조회

## 기본 사용자 흐름

1. 사용자가 서비스에 접속한다.
2. 정책자금 기관과 제도 개요를 확인한다.
3. 기업 상태 체크 항목을 입력한다.
4. 조건에 맞는 정책자금 추천 결과를 확인한다.
5. 추천된 자금별 필요 서류와 발급 방법을 확인한다.
6. 공식 기관 사이트에서 실제 신청을 진행한다.

## 데이터 관리 방향

정책자금 정보는 변경될 수 있으므로 공식 기관 자료를 기준으로 관리합니다.

관리해야 할 주요 데이터:

- 기관 정보
- 정책자금 정보
- 신청 조건
- 필요 서류
- 서류 발급 경로
- 신청 링크
- 업데이트 날짜

정책자금 추천 결과에는 항상 최신성 확인을 위한 기준일을 표시하는 것이 좋습니다.

## 향후 확장 방향

- 챗봇 기반 정책자금 질의응답
- 지역별 지원사업 추천
- 업종별 맞춤 정책자금 추천
- 신청 가능성 점수화
- 신청 서류 체크리스트 저장
- 알림 기능
- 관리자용 정책자금 데이터 관리 페이지

## 주의사항

본 서비스는 정책자금 정보를 쉽게 탐색하고 신청 준비를 돕기 위한 안내 서비스입니다. 실제 신청 가능 여부, 심사 결과, 대출 한도, 금리 등은 각 기관의 심사 기준과 최신 공고에 따라 달라질 수 있습니다. 따라서 최종 신청 전에는 반드시 공식 기관의 공고와 안내를 확인해야 합니다.
