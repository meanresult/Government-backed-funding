# 05. 운영기술명세 (참고 부록)

스프레드시트 기반 간이추천 시스템을 실무 상담이나 초기 검증에 활용하기 위한 참고 문서입니다. 웹서비스 본 설계의 메인 읽기 흐름보다는 `운영 참고 부록` 성격으로 사용합니다.

## 문서 개요

- 기준일: `2026-05-01`
- 대상 산출물: `정책자금_간이추천시스템.xlsx`, `정책자금_간이추천시스템_서류안내확장.xlsx`
- 문서 목적: 스프레드시트 기반 정책자금 간이추천시스템의 입력 구조, 추천 규칙, 운영 방식, 유지보수 기준을 정의한다.

## 1. 시스템 목적

본 시스템은 소상공인 상담 또는 1차 사전진단 단계에서 최소 입력값만으로 신청 가능성이 높은 정책자금을 빠르게 추려주는 간이 추천 도구이다.

핵심 목표는 아래와 같다.

- 개인정보를 거의 받지 않고도 1차 자금 분류를 수행한다.
- 체납, 제외업종, 소상공인 기준 미충족 같은 공통 탈락 사유를 즉시 안내한다.
- 자금별 추천 후보와 추가 확인 필요사항을 동시에 제시한다.
- 실제 접수 전 필요한 증빙 확인 포인트를 상담사가 놓치지 않도록 돕는다.

## 3. 적용 자금 범위

현재 파일은 아래 6개 자금을 기준으로 간이 추천한다.

- 일시적경영애로자금(홈플러스 피해)
- 일시적경영애로자금(직접대출)
- 신용취약소상공인자금
- 상생성장지원자금
- 혁신성장촉진자금
- 재도전특별자금

## 4. 시트 구성

| 시트명 | 역할 | 운영 메모 |
| --- | --- | --- |
| `추천시스템` | 사용자 입력과 자동 추천 결과를 보여주는 메인 시트 | 상담 시 이 시트만 사용해도 된다 |
| `규칙` | 자금별 상태 계산, 공통 탈락 판단, 보조 계산식 저장 | 일반 사용자에게는 숨김 처리 가능 |
| `옵션` | 드롭다운 원본 옵션 관리 | 선택값 추가 또는 변경 시 수정 |
| `자금설명` | 자금별 간이 기준과 주의사항 요약 | 상담 참고 자료로 활용 |

서류안내 확장판은 위 구성에 아래를 추가로 가진다.

| 시트명 | 역할 | 운영 메모 |
| --- | --- | --- |
| `서류안내` | 문서명, 발급처, 발급방법, 제출 시점을 표로 정리 | 상담 중 바로 보여주기 좋은 참고 시트 |

## 5. 입력 구조

입력은 모두 `추천시스템` 시트 좌측 영역에서 수행한다.

- 기본판 입력 범위: `B4:B31`
- 서류안내 확장판 입력 범위: `B4:B34`

### 5.1 공통 자격 확인

- 체납 여부
- 사업자 형태
- 공동대표 여부
- 업종 구분
- 상시근로자 수
- 폐업/휴폐업 이력 여부

### 5.2 사업 현황

- 온라인 판매 여부
- 수출 여부
- 최근 3개년 매출 구간
- NICE 신용점수 구간

### 5.3 점유 및 주거 정보

- 사업장 형태: 자가 / 임차 / 전대 / 무상사용
- 사업장 권리침해 여부
- 사업장 보증금
- 사업장 월임대료
- 주거 형태: 자가 / 임차
- 주거 보증금
- 주거 월임대료

### 5.4 혁신 및 성장 정보

- 스마트기술 도입
- 스마트공장
- 특허/지식재산
- ESG 인증
- 플랫폼 입점 / TOPS / POST-TOPS
- 로컬크리에이터

### 5.5 특수 사유

- 홈플러스 입점
- 재난피해
- 지정지역 소재

### 5.6 서류안내 확장판 추가 입력

- 공동대표 수
- 시설자금 신청 여부
- 운송·선박 영업용 임차 사용 여부

## 6. 출력 구조

자동 결과는 `추천시스템` 시트 우측 영역에서 확인한다.

- `E5`: 1차 판정
- `E6`: 신청 불가 사유
- `E8`: 우선 추천 자금
- `E10`: 추가 검토 자금
- `E12`: 추가 확인 필요사항

서류안내 확장판은 아래 출력이 추가된다.

- `E14`: 기본 제출 권장 서류
- `E16`: 심사 후 또는 필요 시 제출 서류
- `E18`: 신청 제한 관련 안내
- `E20`: 발급처/발급방법 요약

출력값은 단순 추천 목록이 아니라 아래 순서로 해석한다.

1. 공통 탈락 여부를 먼저 확인한다.
2. 우선 추천 자금이 있으면 현재 조건으로 가장 먼저 검토한다.
3. 추가 검토 자금은 증빙 또는 세부 이력 확인 후 상담사가 재판단한다.
4. 추가 확인 필요사항은 실제 접수 전 반드시 보완한다.

## 7. 공통 판정 로직

아래 조건은 공통 탈락 또는 강한 제한 요인으로 본다.

- 국세·지방세 체납
- 제외업종 해당
- 사업장 권리침해 존재
- 소상공인 기준 초과

소상공인 기준은 업종별 상시근로자 수로 단순 판정한다.

- 도소매업, 음식점업/숙박업, 서비스업: `5인 미만`
- 제조업, 운수업/건설업/광업: `10인 미만`

필수 입력값이 비어 있으면 추천보다 먼저 `입력 필요` 상태를 보여준다. 필수 입력값은 아래 항목이다.

- 체납 여부
- 사업자 형태
- 공동대표 여부
- 업종 구분
- 상시근로자 수
- 폐업/휴폐업 이력 여부
- NICE 신용점수 구간
- 사업장 형태
- 사업장 권리침해 여부
- 주거 형태

## 8. 자금별 간이 추천 규칙

### 8.1 일시적경영애로자금(홈플러스 피해)

- `홈플러스 입점 = 예`이면 우선 추천
- 실제 접수 전 입점 계약자료와 영업 사실 확인자료 필요

### 8.2 일시적경영애로자금(직접대출)

- 최근 연도 매출이 저매출 구간이고 `재난피해` 또는 `지정지역 소재`이면 우선 추천
- 최근 연도 매출이 저매출 구간이고 직전 연도 대비 매출 15% 이상 감소로 추정되면 추가 검토
- 실제 감소율은 증빙자료로 재확인 필요

### 8.3 신용취약소상공인자금

- NICE 기준 저신용 구간이면 우선 추천
- 현재 파일에서는 `839점 이하`를 참고 기준으로 사용
- 신용관리교육은 후속 보완자료로 안내할 수 있다
- 실제 공식 심사는 `NCB 기준`이므로 현장 접수 전 반드시 재확인 필요

### 8.4 상생성장지원자금

- `온라인 판매 = 예`이면 우선 추천
- 단, 온라인 판매만으로 추천된 경우에는 `TOPS/POST-TOPS 참여 필요`를 신청 단계 안내로 함께 표시
- `플랫폼 입점 / TOPS / POST-TOPS = 예`이면 더 강한 추천 근거로 표시
- 플랫폼 입점 증빙, TOPS/POST-TOPS 확인자료, 플랫폼 추천 확인자료 등 별도 확인 필요

### 8.5 혁신성장촉진자금

- 아래 중 하나라도 충족하면 우선 추천
- 스마트기술 도입
- 스마트공장
- 수출 여부
- 로컬크리에이터
- 최근 3개년 고성장 추정

아래 항목은 우선 추천보다 약한 신호로 보고 추가 검토로 반영한다.

- 특허/지식재산
- ESG 인증

### 8.6 재도전특별자금

- `폐업/휴폐업 이력 = 예`이면 추가 검토
- 현재 폐업 상태인지, 과거 이력인지, 재창업 여부가 추가 확인 포인트다

## 9. 운영 절차

### 9.1 상담 또는 사전진단

상담사 또는 사용자가 `추천시스템` 시트 좌측 입력값만 선택한다. 체크박스 성격 항목은 `예/아니오` 드롭다운으로 구현한다.

### 9.2 자동 판정 확인

우측 결과 영역에서 아래 순서로 해석한다.

1. `1차 판정`
2. `신청 불가 사유`
3. `우선 추천 자금`
4. `추가 검토 자금`
5. `추가 확인 필요사항`

### 9.3 후속 증빙 안내

추천 자금이 나오면 `추가 확인 필요사항`과 `자금설명` 시트를 함께 보며 아래 자료를 추가로 받는다.

- 임대차계약서, 전대 동의서
- 홈플러스 입점 계약자료
- 재난피해 확인서
- 지정지역 증빙
- 매출 감소 증빙
- 수출실적 자료
- 스마트기술 또는 스마트공장 확인자료
- 신용 관련 공식 조회 결과

### 9.4 최종 신청 전 재검토

본 파일은 간이 추천 도구이므로 실제 신청 전에는 아래를 다시 확인해야 한다.

- 최신 공고문 기준 자격요건
- 실제 신용평가 기준
- 실제 매출 증빙
- 휴폐업 및 재창업 이력
- 사업장 권리관계

## 10. 개인정보 및 운영 원칙

본 시스템은 개인정보 최소수집 원칙을 따른다.

- 대표자명, 사업자등록번호, 주민번호, 연락처는 기본 입력값에서 제외한다.
- 로그인 이력이나 사용자 계정 기반 저장을 전제로 하지 않는다.
- 추천 정확도보다 상담 진입 속도와 프라이버시 보호를 우선한다.
- 실제 접수 단계에서만 원본 증빙과 실명 정보를 별도로 수집한다.

## 11. 유지보수 기준

공고문이 바뀌면 아래 순서로 수정한다.

1. `자금설명` 시트의 기준 문구를 먼저 업데이트한다.
2. `옵션` 시트에서 드롭다운 값 변동 여부를 확인한다.
3. `규칙` 시트에서 자금별 상태 계산식을 수정한다.
4. `추천시스템` 시트 우측 안내 문구를 함께 조정한다.
5. 변경 후 대표 시나리오 5개 이상으로 결과를 수동 검증한다.

대표 검증 시나리오는 아래를 포함하는 것이 좋다.

- 체납으로 즉시 탈락하는 경우
- 제외업종으로 탈락하는 경우
- 홈플러스 피해로 바로 추천되는 경우
- 저신용으로 신용취약자금만 검토되는 경우
- 혁신/수출 조건으로 혁신성장촉진자금이 추천되는 경우
- 폐업 이력으로 재도전특별자금이 검토되는 경우

## 12. 한계 및 주의사항

- 본 파일은 정밀 심사 시스템이 아니라 `간이 추천 시스템`이다.
- 매출은 구간값 입력이라 실제 감소율과 성장률을 정확히 계산하지 않는다.
- NICE 점수는 참고용이며, 공식 심사 기준과 다를 수 있다.
- 공동대표, 전대, 재도전 이력처럼 사실관계가 복잡한 사안은 추가 인터뷰가 필요하다.
- 실제 지원 가능 여부는 최종적으로 공단 접수 기준과 심사 결과에 따라 달라질 수 있다.
