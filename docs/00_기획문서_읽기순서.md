## 문서 운영 원칙

- 메인 읽기 흐름은 `서비스/기획/시스템` 문서와 `규칙/서류` 문서 위주로 유지한다.
- 스프레드시트 운영 문서와 개인 메모는 `부록/참고`로 분리한다.
- 공식 기획 문서는 가능한 한 한국어 파일명과 한국어 섹션 제목을 사용한다.
- 메인 문서는 읽는 순서가 드러나도록 `00`, `01`, `02` 방식의 번호 체계를 유지한다.
