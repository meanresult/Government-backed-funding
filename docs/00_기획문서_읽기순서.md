## 개발 흐름 기준 해석

위 문서들은 아래 순서로 이어진다.

1. `어떤 사용자 경험을 만들 것인가`
2. `그 경험을 위해 어떤 기능이 필요한가`
3. `그 기능들이 시스템 안에서 어떻게 연결되는가`
4. `그 시스템을 어떤 기술과 운영 절차로 구현할 것인가`
5. `MVP 또는 현장 운영에서 어떤 도구와 규칙으로 바로 활용할 것인가`

즉, `화면 -> 요구사항 -> 시스템 구조 -> 기술/운영 구조 -> 실무 운영 도구` 순서로 이해하면 전체 맥락이 가장 잘 잡힌다.
