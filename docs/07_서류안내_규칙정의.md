## 1. 공통 신청/동의·자동확인 원칙

- 결과 화면은 `문서명 / 발급처 / 발급방법 / 제출 시점`을 함께 보여준다.
- 모든 항목을 업로드 서류처럼 다루지 않고, `신청 시 작성/동의`, `공공마이데이터·행정정보 공동이용 기반 자동확인`, `직접 제출`, `심사 보강`으로 나눠서 안내한다.
- 서류 추천은 `자금 추천`과 분리해서 계산하되, 기업 상태와 사업장 상태를 함께 반영한다.
- `주된 사업장` 기준이 필요한 서류는 반드시 그 문구를 함께 안내한다.
- `권리침해`가 있는 사업장처럼 사실상 신청 제한이 걸리는 조건은 서류 추천보다 먼저 `신청 제한 관련 안내`를 노출한다.
- 공동대표가 있으면 동일 규칙을 공동대표 수만큼 반복 적용한다.
- 최종 화면은 자금별 카드 단위로 서류를 보여주는 것이 원칙이다.

### 1.1 제출 시점 분류

- `신청 시 작성/동의`: 신청서 작성, 사업계획 입력, 전자 동의처럼 업로드 파일이 아닌 항목
- `자동확인`: 공공마이데이터, 행정정보 공동이용, 내부 조회로 우선 처리하는 항목
- `기본 제출 권장`: 상담 초기에 바로 받는 편이 좋은 서류
- `심사 후 또는 필요 시 제출`: 지금 받아도 되지만 보통 심사 보강자료로 쓰이는 서류
- `신청 제한 관련 안내`: 서류보다 사실관계가 먼저 문제되는 경우

### 1.2 공통 신청 항목 처리

- `신청서류`
  실제 신청 화면에서 작성하거나 제출하는 항목이다.

- `동의서`
  파일 업로드보다 `전자 동의` 또는 `체크 후 전자서명`으로 처리하는 편이 맞다.

- `대표자 확인`, `사업자 확인`, `업종 확인`, `상시근로자 확인`, `세금 확인`, `주소 확인`
  원칙적으로 `자동확인` 항목이다. 공공마이데이터 또는 행정정보 공동이용으로 우선 확인하고, 조회 실패나 예외 케이스일 때만 증빙서류를 붙인다.

- `재무자료`
  모든 신청에서 초기에 제출받기보다 자금 유형 또는 심사 단계에 따라 `심사 후 또는 필요 시 제출`로 두는 편이 적절하다.

## 3. 사업장/법인/거주/공동대표 규칙

### 3.1 사업장 관련

- `자가`
  원칙은 `등기부등본`이고, 등기부 확인이 곤란하거나 미등기인 경우 `토지대장`, `건축물대장`으로 대체한다.

- `임차`
  `사업장 임대차계약서`와 `등기부등본`을 안내한다. `권리침해 = 예`이면 신청 제한 관련 안내를 함께 보여준다.

- `전대`
  `사업장 임대차계약서` 또는 `전대차계약서`, 필요 시 `임대인 전대차동의서`를 안내한다. `권리침해 = 예`이면 신청 제한 관련 안내를 함께 보여준다.

- `무상사용`
  `사업장 무상사용 사실확인서`를 안내한다.

- `영업용 차량 사용 업종`
  `자동차등록원부등본`을 안내한다.

- `운송업 또는 선박업` 성격이고 `임차한 영업용 차량·선박 사용 = 예`
  `위수탁지입계약서`를 함께 안내한다.

### 3.2 법인

- `법인 인감증명서(1개월 이내)`
- `법인 등기사항 전부증명서(1개월 이내)`
- `주주명부`
- `주식등변동상황명세서`
- `고용·산재보험료 완납증명서`

### 3.3 거주주택 관련

- 대표자와 공동대표 각각에 대해 `거주형태`를 확인한다.
- `자가`
  `거주주택 등기사항 전부증명서`
- `임차`
  `거주주택 임대차계약서`
- `무상거주`
  `무상거주 사실 확인서`

### 3.4 공동대표

- `공동대표 여부 = 예`이면 공동대표 수만큼 아래 규칙을 반복 적용한다.
- 공동대표별 거주형태가 `자가`면 거주주택 권리확인 서류를 안내한다.
- 공동대표별 거주형태가 `임차`면 거주주택 임대차계약서를 안내한다.
- 공동대표별 무상거주 성격이 있으면 무상거주 확인 성격 서류를 안내한다.

### 3.5 업종별 조건부 서류

- `통신판매업` 성격이 있으면 `통신판매업신고증 사본`
- `영업용 차량 사용 업종`이면 `자동차등록원부등본`

## 5. 최종 출력 조합 예시

### 5.1 최종 조합 방식

자금 하나에 대한 최종 서류 목록은 아래처럼 만든다.

```text
최종 안내 =
공통 신청/동의
+ 공통 자동확인
+ 사업장/법인/공동대표 등 상태별 기본서류
+ 자금 공통 추가서류
+ 자금 세부유형 추가서류
+ 심사 보강자료
```

예를 들어 `혁신성장촉진자금(스마트기술유형)`이면 아래처럼 나와야 한다.

```text
공통 신청/동의
+ 공통 자동확인
+ 사업장 임차 기본서류
+ 거주주택 기본서류
+ 법인 추가서류(법인일 때)
+ 공동대표 추가서류(공동대표일 때)
+ 혁신성장촉진자금 세부유형 서류(스마트기술)
+ 필요 시 거래내역 보강자료
```

4. `BASE-02` 사업장 권리세트-자가
5. `BASE-11` 거주주택 권리세트-자가
6. `FUND-CV-01` 신용취약 추가서류

운영 기준상 `839점 이하`이면 추천은 바로 가능하고, 교육 이수확인은 후속 보완으로 내려도 된다.

## 6. 구현 해석

- `신청서류`, `전자 동의`, `자동확인 항목`은 업로드 서류 목록과 분리해서 보여주는 편이 맞다.
- `대표자 확인`, `사업자 확인`, `업종 확인`, `상시근로자 확인`, `세금 확인`, `주소 확인`은 기본적으로 `자동확인`으로 표시하고, 예외 시에만 대체 증빙을 안내한다.
- `권리침해 = 예`이면 등기부등본 안내는 유지하되, 결과 최상단에 먼저 `신청 제한 관련 안내`를 보여주는 편이 맞다.
- `시설자금 신청 여부 = 예`이면 자금 추천 결과와 무관하게 시설투자계획서를 조건부 추가 서류로 붙일 수 있다.
- `공동대표 여부 = 예`이면 단일 문구보다 `공동대표 n명 각각 추가 확인 필요`처럼 반복 개념을 노출하는 편이 실무에 가깝다.
- `거주주택 관련 서류`는 대표자와 공동대표 각각의 거주형태에 따라 별도 계산하는 것이 맞다.
- `통신판매업신고증 사본`과 `자동차등록원부등본`은 공통 기본서류가 아니라 업종별 조건부 서류로 취급하는 편이 적절하다.
- `임차료`와 `임금` 이체확인 자료는 필수 입력값이 아니라 보강자료이므로, 추천 단계에서는 안내만 하고 심사 서류로 분류하는 것이 적절하다.
- 안내자료 원문 기준으로 `사업장 임대차계약서`와 사업장 권리확인 서류는 `주된 사업장` 기준이므로, 결과 문구에 아래 의미를 함께 넣는다.

```text
제조업: 공장 기준
그 밖의 업종: 본점·주사무소 또는 사업자등록상 주사업장 기준
여러 업종 겸영 시: 매출 비중이 가장 큰 업종의 주사업장 기준
```
