## 6. 혁신성장촉진자금 변경사항 반영

`혁신성장촉진자금 변경 내용.pages` 기준으로 아래 변경이 확인된다.

- 접수 방식이 `매월 접수`에서 `분기별 접수`로 변경
- 스마트기술 유형 일부가 조정 또는 제외
- 이미 시장에 널리 보급되었거나 정책상 혁신성 인정이 낮은 기술은 우선 제외 방향

따라서 `혁신기술` 항목은 단순 보유 여부보다 아래를 같이 봐야 한다.

- 실제 사업현장에 설치되어 있는가
- 경영효율화 또는 매출창출에 직접 쓰이고 있는가
- 시장에서 흔한 범용장비가 아니라 정책상 혁신성 설명이 가능한가

## 8. 실무용 추천 평가체계

공식 문서에는 자금별 세부 배점표가 명시되어 있지 않으므로, 실제 상담 또는 사전선별용으로는 아래처럼 `적격/부적격`과 `우선순위 점수`를 분리하는 것이 좋다.

### 8-1. 1차 적격 체크

| 항목 | 판정 |
|---|---|
| 소상공인 기준 충족 | Yes / No |
| 영리기업 여부 | Yes / No |
| 제외업종 여부 | Yes / No |
| 휴·폐업 여부 | Yes / No |
| 세금체납/금융연체 여부 | Yes / No |
| 사업장·거주주택 권리침해 여부 | Yes / No |
| 자금별 필수요건 충족 여부 | Yes / No |

### 8-2. 2차 우선순위 평가 예시(추천안)

| 평가영역 | 배점 | 평가 포인트 |
|---|---:|---|
| 자금 적합도 | 25 | 해당 자금의 핵심 대상 여부가 명확한가 |
| 재무건전성 | 20 | 매출추세, 차입부담, 임대료·인건비 감당 가능성 |
| 신용위험 | 15 | 신용점수, 연체이력, 성실상환 여부 |
| 사업 지속성 | 15 | 실영업 여부, 점포/공장 운영 안정성, 거래내역 |
| 성장성/혁신성 | 15 | 스마트기술, 온라인, 수출, 지식재산, 전문성 |

## 9. 상담/접수용 최소 입력 폼 추천

여러 자금을 동시에 검토하려면 아래 항목은 한 번에 받는 것이 효율적이다.

- 기본정보: 업체명, 대표자명, 사업자번호, 개인/법인, 공동대표 여부
- 업종정보: 업종코드, 주업종, 제조 여부, 온라인 판매 여부, 수출 여부
- 사업이력: 개업일, 휴폐업 이력, 재창업 여부, 사업장 이전 여부
- 매출정보: 최근 3년 매출, 최근 1년 매출, 최근 분기/월 매출 추이
- 인력정보: 상시근로자 수, 최근 고용증가 여부, 채용계획 인원
- 신용정보: 대표자 신용점수, 연체 여부, 채무조정 여부
- 사업장정보: 자가/임차/전대/무상사용, 보증금, 월임대료, 권리침해 여부
- 주거정보: 대표자 거주주택 자가/임차 여부
- 혁신정보: 스마트기술 도입 여부, 스마트공장, 특허, ESG 인증
- 성장정보: 플랫폼 입점, TOPS/POST-TOPS, 수출실적, 로컬크리에이터 여부
- 특수사유: 홈플러스 입점, 재난피해, 지정지역 소재 여부
- 제출가능서류: 재무제표, 부가세 자료, 임대차계약서, 등기부, 납세증명서, 사업성 사진 보유 여부

## 10. 정리

- `신용취약`, `경영애로`, `재도전`, `혁신성장`, `상생성장`은 서로 보는 포인트가 다르지만, 실제 사전심사 데이터는 상당 부분 공통화할 수 있다.
- 특히 `업종`, `상시근로자`, `매출추이`, `신용점수`, `재도전 이력`, `혁신기술`, `사업장 권리관계`, `임대료·인건비 지급능력`을 함께 받으면 대부분 자금의 1차 분류가 가능하다.
- 실무적으로는 `공통 입력폼 1개 + 자금별 추가질문` 구조가 가장 효율적이다.
