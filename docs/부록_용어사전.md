# 부록. 용어사전

정책자금 추천 서비스 문서에서 반복해서 쓰는 핵심 용어를 짧게 정리한 참고 문서입니다.

## 용어

- `세부유형`
  같은 자금 안에서 심사 포인트나 추가서류가 달라지는 하위 분기다. 예: 혁신성장촉진자금의 `스마트기술유형`, `수출유형`.

- `자동확인`
  사용자가 파일을 직접 올리지 않고, 공공마이데이터·행정정보 공동이용·내부 조회로 우선 확인하는 항목이다.

- `기본 제출 권장`
  신청 단계에서 함께 준비하면 좋은 직접 제출 서류를 뜻한다.

- `심사 후 제출`
  초기에 꼭 업로드하지 않아도 되지만, 심사 과정에서 보강자료로 요청될 가능성이 높은 서류를 뜻한다.

- `variant`
  개발 문서에서 `세부유형`을 가리키는 내부 표현이다.

- `bundle`
  여러 서류나 안내 항목을 묶어서 계산하기 위한 내부 단위다. 예: `BASE-03 사업장 권리세트-임차`.

- `follow-up group`
  1차 추천 이후에 세부유형 확정이나 추가서류 판단을 위해 여는 후속 질문 묶음이다.
